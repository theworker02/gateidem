# gateidem

Gate encode/decode helpers for idem payloads in pipelines.

**Site:** https://theworker02.github.io/gateidem/

## Install / run

```bash
git clone https://github.com/theworker02/gateidem.git
cd gateidem
node src/cli.js
node --test
```
